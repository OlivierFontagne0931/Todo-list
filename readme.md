# Mini application de suivi de tâches

------

# Technologies utilisées

- HTML5, CSS3, JavaScript, Git & GitHub et VScode

------

# Déroulé du projet

- Récupération du champs de saisie <input>
- Récupération du bouton <button>
- Récupération de la liste <ul>
- Affichage dans la console
- Ajout d'un événement "click" sur le bouton "Ajouter"
- Ajout dans la console "Button waz clicked"
- Récupération du contenu de l'input et affichage dans la console
- Création d'un élément <li> pour chaque tâche et ajout dans la liste
- Ajout du texte de là tâche à l'élément <li>
- Ajout de l'élément <li> dans la <ul>
- Réinitialisation du champ de saisie

------

# Dificultés rencontrées

- Trouver les bon éléments à intégrer dans le JavaScript
- Respecter le déroulé étape par étape
- Récupérez le contenu de l'input et l'afficher dans la console
